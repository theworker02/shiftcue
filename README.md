# shiftcue

Shift timestamps and cue durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/shiftcue/

## Install / run

```bash
git clone https://github.com/theworker02/shiftcue.git
cd shiftcue
node src/cli.js
node --test
```
